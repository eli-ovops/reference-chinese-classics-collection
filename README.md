# Chinese Classics, Collected

**A reference collection for exploring Chinese classical texts and related analysis material, with the source files and their original notices retained.**

## What you will find

A reference workspace for studying an upstream project. Its original authorship, licenses and notices remain in place; this copy is not presented as a newly authored replacement.

## Current scope

This snapshot includes 2269 source files. Original media, databases, private account records and other unprocessed attachments were not included in this text-and-source release.

This update improves the English presentation. It does not rerun the project, install a skill, reproduce an old test, or establish production readiness. Some original working documents retain their source language; machine-specific paths or setup assumptions may still need adaptation.

## Sources and license

The owner's original contributions and new presentation notes follow the [retained license](LICENSE). Third-party material keeps its own licenses and attribution; this does not relicense it.
